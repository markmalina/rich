# Создать «БАЗУ» Rich в Google Таблицах

Нужен ИИ с доступом к этому репозиторию и возможностью создавать и изменять Google Таблицы в выбранном аккаунте. Запрос в [README](../README.md) разрешает создать новый файл. Его владелец — Google-аккаунт, от имени которого создаётся файл. Для частной базы сохраняйте исходные права доступа файла и выдавайте дополнительные права по поручению владельца. Telegram и Face можно подключить отдельно.

## Установка

1. Возьмите [схему `rich-google-base-v1`](../schemas/google-base-v1.json). Сохраните названия вкладок, порядок колонок, локаль `ru_RU` и часовой пояс `Europe/Moscow`. Поля с `formula` записывайте как формулы, остальные — как значения.
2. Создайте файл «БАЗА · Rich» от имени подключённого пользователя. Если инструмент сначала создаёт пустой файл, прочитайте фактический ID его пустой первой вкладки и переиспользуйте её. Применяйте установочный пакет только к только что созданному пустому файлу. Если установка прервалась, продолжайте в этом же файле, предварительно сверив уже созданные вкладки.
3. Сверьте заголовки всех шести вкладок, начальный справочник и метаданные. Во вкладке «Правило» проверьте название Rich, ссылку на репозиторий, ссылку на общие правила и `rich-google-base-v1`. Формулы находятся в `События!P2`, `Действия!G2` и `Экспорт Faces!A2`. Первые две считают описание и категорию. Полный экспорт начинает возвращать строки после добавления событий разрешённых категорий. Покажите пользователю ссылку после обратной проверки.
4. Для работы откройте [промпт помощника](../tracking/assistant-prompt.md). Владелец может дополнять правила с `Правило!A7`, подбирать действия и указывать свой вес в `Действия!I2` при желании. Служебные формулы должны сохраняться.

| Вкладка | Назначение |
| --- | --- |
| Входящие | Источник, время получения, оригинал или ссылка, распознанный текст и связь со временем события |
| События | Строки учёта с ID входящего и постоянным ID события |
| Действия | Справочник, родительские категории, единицы и параметры расчётов |
| Правило | Связь с Rich, версия и правила владельца |
| Faces | Настройки отдельных витрин |
| Экспорт Faces | Служебный расчёт данных для витрин |

### Для ИИ с инструментом Google Sheets API

Генератор на Python 3.10+ печатает JSON для Google Sheets API. Он работает автономно, без ключей и сетевого доступа.

```bash
# Тело для POST https://sheets.googleapis.com/v4/spreadsheets
python -m tracking.bootstrap --title 'БАЗА · Rich'

# Пакет batchUpdate после создания пустого файла. Подставьте реальный ID первой вкладки.
python -m tracking.bootstrap --title 'БАЗА · Rich' --batch --default-sheet-id 123456789
```

Ассистент без среды Python может собрать те же запросы из [JSON-схемы](../schemas/google-base-v1.json). При установке передайте в API поля `userEnteredValue.formulaValue` для формул, `stringValue` для текста и `numberValue` для чисел. Ожидаемые колонки и примеры записи зафиксированы в [правилах](../tracking/event-rules.md). [Метод создания в Google Sheets API](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets/create) · [Пакетное обновление](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets/batchUpdate)

Если ИИ может только читать подключённый Google Диск, он может подготовить установочный JSON и показать владельцу, какие действия нужны для записи. Считайте таблицу созданной после получения ссылки и обратной проверки структуры.

## Начать вести записи

Пример первого сообщения после установки: «Сегодня в 8:10 сделал 15 отжиманий, подход занял одну минуту». Затем спросите «Какие упражнения я сегодня делал?». Проверьте исходник во «Входящих», связь со строками «Событий» и ответ из журнала. Если для расчёта энергии нет веса или MET, значение остаётся пустым.

Для уже существующей таблицы сперва прочитайте её схему и правила. Перенос данных между версиями выполняется отдельно, с сохранением входящих и ID событий.
