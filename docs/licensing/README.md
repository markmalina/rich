# Лицензирование System Rich

Решение о модели принято владельцем проекта 9 октября 2026 года. Этим пакетом условия явно применяются к перечисленным материалам текущего репозитория в пределах прав, которые их правообладатели могут предоставить. Нового согласования каждого использования или форка не требуется.

Точная карта файлов: [LICENSING.json](../../LICENSING.json). Заголовки SPDX и соседние файлы `.license` для JSON уточняют лицензирование, не меняя рабочие данные схем. Это разделение объектов, а не двойная лицензия по выбору на один и тот же файл.

Корневой [LICENSE](../../LICENSE) — уведомление о применении. Полные неизменённые условия: [AGPL-3.0-only](../../LICENSES/AGPL-3.0-only.txt) и [CC-BY-SA-4.0](../../LICENSES/CC-BY-SA-4.0.txt).

## Авторство и уведомления

Указывайте проект **System Rich**, ссылку **https://github.com/markmalina/rich** и сохраняйте сообщённые авторские уведомления. Индивидуальные вклады и их авторство отражаются в истории Git; основной проект не присваивает чужие права. Основатель проекта — Марк Малиновский (markmalina).

Для копий и адаптаций сохраняйте применимые лицензионные уведомления. Для CC-материалов указывайте изменения и ссылку на лицензию; при распространении адаптации соблюдайте ShareAlike. Разумная атрибуция может выглядеть так:

> Основано на материалах System Rich: https://github.com/markmalina/rich. Авторы — участники проекта согласно уведомлениям и истории Git. Материалы распространяются по CC BY-SA 4.0: https://creativecommons.org/licenses/by-sa/4.0/. Изменения: {краткое описание}.

Для программной части сохраняйте AGPL-уведомления и указывайте изменения по применимым условиям лицензии. Не считайте пример атрибуции заменой полного текста лицензии.

## Обязанности и границы

AGPL допускает использование, изменение, ответвления и коммерческие услуги. При передаче покрываемой программы действуют требования к соответствующим исходникам и лицензированию. Если изменённая версия поддерживает удалённое сетевое взаимодействие, §13 требует явно предложить всем её удалённым пользователям бесплатно получить соответствующие исходники этой версии.

CC BY-SA допускает использование и адаптации, включая коммерческие. Условия авторства и ShareAlike применяются при распространении материалов/адаптаций; лицензия не вводит обязанности предоставлять программные исходники или раскрывать каждый частный промпт.

Ни одна из этих лицензий не обязывает передать улучшения именно основателю, получить разрешение на форк или включить изменения в основной проект. Возврат полезных улучшений приветствуется по [CONTRIBUTING](../../CONTRIBUTING.md). Публикация для всего мира и предоставление исходников конкретным пользователям — разные действия.

Лицензии не создают исключительных прав на идеи, факты, общие методы или неохраняемые элементы схем. Они не дают права раскрывать частную информацию и не предоставляют прав на товарные знаки. Порядок официального статуса: [BRAND_POLICY](../../BRAND_POLICY.md).

## Новые файлы и интеграция

Перед включением нового файла укажите его лицензию и автора в SPDX-заголовке либо соседнем `.license` и добавьте путь в LICENSING.json. Для самостоятельной документации используется CC-BY-SA-4.0; для программной реализации — AGPL-3.0-only.

Если промпт, текстовая схема или материал документации становится частью программного исходника, оцените совместимость перед включением: нельзя просто заменить лицензию скопированного чужого или ранее принятого CC-вклада. Для смешанных компонентов может понадобиться отдельное разрешение автора или разрешённый лицензиями способ сочетания.

Машинные схемы не являются готовым сервером. Классификация JSON как программного интерфейсного исходника не доказывает охраноспособность каждого поля и не создаёт сетевой обязанности для всякого использования таблицы или инструкции.

Сторонние ассистенты, Google Таблицы и другие независимые инструменты не становятся AGPL-компонентами только потому, что используются с протоколом. Для будущей составной программы границы соответствующих исходников и совместимость зависимостей проверяются по её реализации.
