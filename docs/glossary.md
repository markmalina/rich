# Словарь Rich и eRex

Актуальные обозначения с 24 ноября 2026 года.

| Обозначение | Значение |
| --- | --- |
| **Rich** | Система Life Tracking. Хранит повседневные события и связанные записи. Пишется латиницей через **i**, с заглавной **R**. |
| **System Rich** | Полное название того же проекта в материалах сайта и репозитория. |
| **Life Tracking**, **лайф-трекинг** | Учёт повседневной жизни и движения к целям. Темы включают здоровье, питание, активность, чтение, привычки, проекты и финансы. |
| **Life Tracker**, **лайф-трекер** | Роль человека или агента, который помогает вести учёт, видеть прогресс и двигаться к целям. |
| **eRex** | Личное имя Telegram-помощника. Строчная **e**, заглавная **R**, далее **ex**. В имени профиля и описаниях используется **eRex**. Смысл имени в проекте — поднимает, помогает расти. |
| **RX** | Сокращение имени eRex, две заглавные латинские буквы **R** и **X**. RX принимает и распознаёт сообщения и передаёт записи в Rich. |
| **@ErexoBot** | Зарегистрированный адрес eRex в Telegram. Используется в ссылках на бота. |
| **Школа лайф-трекеров** | Направление обучения сопровождению людей, которые ведут учёт и работают со своими целями. |
| **БАЗА** | Основная Google Таблица с исходными сообщениями, обработанными событиями и правилами. |
| **Входящие** | Лист с исходным сообщением, ссылкой на оригинал и результатом распознавания. |
| **События** | Лист со структурированными строками учёта, связанными с исходным сообщением. |
| **Действия** | Справочник действий, категорий и параметров учёта. |
| **Правило** | Лист со ссылкой на Rich, версией схемы и личными правилами. |
| **Face** | Витрина с выбранными данными из БАЗЫ. Доступ задаётся отдельно для конкретных получателей. |
| **Faces**, **Экспорт Faces** | Листы настройки витрин и подготовленной для них выгрузки. |
| **Служебный Google-аккаунт** | Аккаунт для хранения файлов и установки синхронизации в выбранной конфигурации. Доступ к каждому файлу определяется его настройками. |
| **Проект RX в OpenAI** | Отдельный проект для запросов распознавания eRex и учёта их расходов. |

## Проверка написания

| Встретилось | Как писать в актуальных материалах |
| --- | --- |
| `Reach`, `Reech` или `RICH` как название системы | **Rich** |
| `Live Tracking`, `live-tracking`, «лайв-трекинг» как название направления | **Life Tracking** или **лайф-трекинг** |
| `Live Tracker`, «лайв-трекер» как название роли | **Life Tracker** или **лайф-трекер** |
| `Health Tracking`, `Health Tracker`, «хелс-трекер» как название всего проекта или роли | **Life Tracking**, **Life Tracker**, **лайф-трекер**. Здоровье остаётся одной из тем учёта. |
| `Erex`, `erex`, `Erexo`, `eRexo`, `Rexo`, `Rex` или «Рекс» как личное имя | **eRex** |
| `rx`, `Rx` или кириллическое «РХ» как сокращение | **RX** |

Примеры. «eRex — мой помощник. Он принимает отчёты, а записи появляются в Rich». «Я лайф-трекер и веду группу». «Открыть eRex в Telegram — [@ErexoBot](https://t.me/ErexoBot)».
