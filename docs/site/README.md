# Сайт System Rich

Решение владельца от 8 октября 2026: опубликовать базовую страницу на `https://system.rich/` через Vercel.

## Границы ответственности

- `markmalina/rich` — продуктовый смысл, тексты, открытые схемы и промпты.
- `AlphaCenter/public`, `apps/system-rich` — исходники сайта, оформление, метаданные, сборка и доказательства публикации.
- Vercel, команда MarkCo — отдельный проект `system-rich` для домена `system.rich`. Публикация через зарегистрированный Ops target; никакие ключи здесь не хранятся.
- Эта страница — описание и вход к инструкциям. Она не принимает данные пользователей и не является интерфейсом частной базы.

## Содержание первой страницы

1. System Rich — база данных для каждого человека, управляемая его личным ИИ-ассистентом.
2. Деньги: доходы, расходы, счета и ресурсы; питание; активность и практики; потребности, возможности, покупки, продажи и помощь людям.
3. Начало: открыть README, создать собственную Google Таблицу, предоставить ассистенту доступ и передать ему инструкции. Подключение и содержимое таблицы остаются частными. Ассистенту нужны инструменты для работы с таблицей; ссылка сама по себе не даёт доступа.
4. Текущий открытый протокол версии 0.3: универсальные входящие, происхождение, автор, предоставивший информацию, владельцы ресурсов и личные принципы. Промпты задают правила; они не запускают фоновые процессы.
5. Планы: ERP для компаний — покупки, заказы, заявки, производство, планы, зарплата, бухгалтерия, финансы, счета. Впоследствии PostgreSQL и дополнительные программные проверки целостности.
6. Будущая модель доверия: взаимодействие только между взаимно доверяющими системами. Основатель подтверждает реальные отношения с регулярными покупателями своего физического продукта — гранолы — на основе продаж, чеков и налогового учёта своих продаж. Участники определяют свои основания доверия. Сертификаты, их проверка, выдача и отзыв пока не реализованы; покупка не означает универсальной гарантии или открытого доступа к данным.
7. Основатель — Марк Малиновский, Марк Малина. Новые точные адреса Mark Malina не предоставлены. В первой редакции используются подтверждённые прежние публичные контакты: https://t.me/MarkMayak и https://www.instagram.com/markmayak.today/.

## Редакционные решения

- Название для этой страницы: **System Rich / система Rich**. Прежнее написание Reach в протоколе — историческое, без изменения схем версии 0.3.
- Фразу владельца «налоги с его доходов» не превращать в утверждение об оплате налогов покупателя. Публичный текст говорит о налоговом учёте продаж основателя.
- Текущие правила хранения не доказывают готовность полной ERP, автоматического контроля целостности или сети доверия. Эти возможности показываются как дальнейшие релизы.
- Временная заглушка доступна по прямой ссылке; `noindex, nofollow` соответствует существующей политике запуска заглушек Public/Ops. Открытие индексации — отдельное изменение.
- Никаких частных таблиц, ID, записей, чеков, личных примеров или секретов в публичных материалах.

## Приёмка

Русскоязычная адаптивная страница, рабочая ссылка на README, шаги запуска, копируемый промпт, контакты основателя; один H1, canonical `https://system.rich/`, robots/noindex, читаемость мобильной версии. Production считается выполненным только после receipt Ops и проверки HTTPS/HTML/ассетов на домене. Связанный текст и описание реализации: [copy.json](copy.json).
