# Rich — личный учёт с собственным ИИ

Rich — система Life Tracking. Она помогает вести учёт повседневных действий и ресурсов в своей Google Таблице. Ваш ИИ принимает сообщения, хранит исходники во «Входящих», записывает связанные «События» и отвечает по данным. Для начала можно взять питание, движения, практики, покупки и переводы.

## Начать с собственной «БАЗЫ»

Дайте ИИ с доступом к Google Таблицам ссылку `https://github.com/markmalina/rich` и этот запрос:

> Прочитай README и docs/google-base.md в репозитории https://github.com/markmalina/rich. Создай новую частную Google-таблицу «БАЗА · Rich» в моём подключённом аккаунте. Возьми структуру из schemas/google-base-v1.json. Проверь вкладки, формулы и ссылки на Rich во вкладке «Правило», затем дай мне ссылку на таблицу. Дальше принимай мои записи по промпту tracking/assistant-prompt.md и правилам tracking/event-rules.md.

- [Установка, проверка и работа с дневником](docs/google-base.md)
- [Машинная структура Google Таблицы](schemas/google-base-v1.json)
- [Промпт для повседневной работы с ИИ](tracking/assistant-prompt.md) и [правила учёта](tracking/event-rules.md)
- [eRex (RX) в Telegram](tracking/telegram-pilot.md) — отдельный способ работы с «БАЗОЙ»
- [Витрины Face](tracking/face.md) — отдельные таблицы для выбранных категорий
- [Словарь проекта](docs/glossary.md)
- [Следующие функции учёта](tracking/roadmap.md)
- [Историческая документация Rich до 21 ноября 2026](docs/history/README.md)

Новая «БАЗА» создаётся в том Google-аккаунте, с которым работает ассистент. Во вкладке «Правило» хранятся версия схемы и ссылки на инструкции Rich. Личные правила и журнал остаются в таблице владельца. В публичном репозитории находятся код, схемы, промпты и вымышленные примеры.
