# Работа с Rich

1. Для новой «БАЗЫ» прочитайте [инструкцию](docs/google-base.md) и [схему](schemas/google-base-v1.json). Продуктовый сценарий — создание таблицы в Google-аккаунте пользователя по его поручению.
2. Для ведения «БАЗЫ» используйте [промпт помощника](tracking/assistant-prompt.md) и [правила учёта](tracking/event-rules.md). Работайте с явно названной или уже привязанной таблицей и проверьте её схему. После записи сверяйте результат обратным чтением.
3. Публичный репозиторий содержит код, схемы, промпты и вымышленные примеры. Частные данные, реальные исходники, ID файлов, рабочие ссылки, токены и секреты храните в частном контуре. Предоставление доступа к таблице и публикация Face требуют решения владельца.
4. При изменении структуры обновите текстовую и машинную спецификации, проверьте совместимость, сохранение существующих записей и связь с исходниками.
5. Обновляйте [карту лицензирования](LICENSING.json), добавляйте SPDX-уведомления и соблюдайте [порядок вклада](CONTRIBUTING.md). Для кода и машинных схем применяется AGPL-3.0-only, для самостоятельных текстов и промптов — CC-BY-SA-4.0.
6. [Инструкции исторического протокола](docs/history/AGENTS.md) относятся к его схеме. Для существующей таблицы сверяйте её версию и работайте по соответствующей документации.
